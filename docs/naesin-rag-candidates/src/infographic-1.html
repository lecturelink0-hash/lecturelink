2핵심 메커니즘

Small-to-Big 계층 청킹

검색은 1,200자 문단(level 1)으로 정밀하게, 생성 컨텍스트는 필요할 때만 부모 슬라이드 블록(level 0)으로 확장. 현행 material_chunks의 결정론적 청킹을 그대로 쓰고 parent_id · level · modality · heading_path만 더한다.

출제 단위가 곧 질의

"자료 분석 → 출제 계획"을 LLM 1콜로 수행해 같은 증례 반복(5문항 중 4문항 동일 증례 실측)을 구조적으로 차단. 단위마다 3질의 + HyDE 가상 발문으로 검색하되, 가상 발문은 생성에 투입하지 않는다(자료 밖 지식 유입 방지).

RRF 융합 · 리랭킹 · MMR

의학 약어·고유명사는 sparse, 서술은 dense가 강하므로 두 순위를 RRF로 합치고 리랭커로 top-6을 고른 뒤 MMR로 같은 문단 중복을 제거. 한국어 형태소 분석기가 없는 Supabase 제약상 sparse는 pg_trgm → 필요 시 bigram BM25.

인용 강제 + 코드 검증

정답·해설의 핵심 주장마다 {id, quote}를 required로 요구(선택이면 신고율 0 수렴 — 현행 source_pages 교훈). 코드가 quote를 원문과 대조해 출처 위치 유효성(구조적)을 문장 단위로 측정하고, 의미상 유효성(전문가)과 분리 보고.

4장점

  • 현행 자산(청크·source_refs·pgvector·Voyage)의 연장선 — 구현 위험 최소
  • 선형 구조라 디버깅·반복 안정성 측정이 쉬움
  • 근거 충실도·출처 위치 유효성·중복률이 처음으로 측정 가능
  • 장문 자료(100쪽+)에서 품질·비용 동시 개선 (lost-in-the-middle 회피)
  • P1 검증 입력 축소로 "근거 없음" 오탐 감소 기대

5단점 · 위험

  • 검색 오류(근거 누락)가 그대로 문항 오류로 전파 — 피드백 루프 없음
  • 품질이 임베딩 모델의 한국어 의학 성능에 종속
  • 이미지 문항은 캡션 품질에 종속
  • 인용 강제가 생성 거부·형식 붕괴 유발 가능 → "좋아졌을 때만 채택"
  • R1(warn 모드)·R2(동일 모델)는 그대로 남음

7교수님께 여쭙는 점

  1. 슬라이드형 자료에서 level 0/1 이중 청킹이 적절한지, 문장군(level 2)까지 필요한지
  2. 한국어 의학 텍스트 임베딩 — voyage-3 vs bge-m3 vs multilingual-e5 — 자체 벤치마크(질의 200·정답 청크 라벨)로 충분한지
  3. 인용 quote 매칭을 "출처 위치 유효성(구조적)"으로 공표 가능한지, 의미상 유효성과 보고를 어떻게 분리할지
  4. 한/영 약어 정규화 — 자체 사전(자체 문항·CPX 룰·오픈 온톨로지 xref)으로 충분한지
