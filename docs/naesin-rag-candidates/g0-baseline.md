# G0 기준선 실측 결과 (RAG 실행계획 v1.1 · 7장 G0 · 8장 기준선)

2026-09-28 · 전재현 · 대상 코드: main 15b3b8f(#273) + #275(PR C) + #276(PDF 렌더 수정)

## 결론

- **G0 6개 항목 중 5개 충족.** 남은 1개(오프라인 검색 품질 Recall@6)는 PR E의 E1~E3 하네스가 들어와야 판정할 수 있음.
- **기준선은 문항당 원가 중앙값 $0.0241, 업로드 처리 시간 p95 146초임.** 따라서 G1 상한은 문항당 $0.0362, p95 219초가 됨.
- **PR C로 인한 회귀는 보이지 않음.** 제공 문항 수는 전 실행 10/10으로 같고, 형식 위반율도 반복 간 변동 범위 안임. 출처 페이지가 달린 문항은 25%에서 99.3%로 늘었고, 25%도 전부 '1쪽'이었던 것이 실제 페이지로 바뀜.
- **새로 확인한 결함·쟁점이 3건 있음**(5장): 스캔 PDF의 OCR 생략 조건(F11), pdfjs 4.10 렌더 회귀(F12, #276), 요금제 원가율.

## 5. 새로 확인한 것

**F11 — 스캔 PDF는 이미지형을 요청하지 않으면 OCR 없이 처리됨.** 전체 페이지 OCR 폴백은 **PDF 전체 글자 수가 1,500자 미만일 때만** 켜짐(`private-generation.ts`, `allowWholePageOcrFallback`). SC1은 109쪽 중 103쪽이 스캔인데 나머지 쪽에서 글자 2,008자가 나와 '텍스트 충분'으로 판정됐음. 그래서 스캔 103쪽을 읽지 않고 2천 자만으로 10문항을 냄. 이 문항들은 강의 내용 대부분과 무관하게 나올 수 있고, RAG에서는 인덱스에 들어갈 청크가 없어 근거 회수율이 구조적으로 떨어짐. 판정을 쪽당 글자 수 기준으로 바꾸는 방안을 Phase 1 C(인덱싱)에서 검토하는 건 어떨까 제안함. 바꾸면 스캔 자료의 OCR 비용이 새로 생기므로, 기준선과 별도 항목으로 원가를 봐야 함.

**F12 — pdfjs 4.10 업그레이드(#122, 2026-08-13) 이후 PDF 페이지 렌더가 잠복 실패 상태였음.** 그림이 있는 쪽에서는 임시 캔버스 라이브러리가 맞지 않아 실패하고, 같은 버퍼를 두 번째로 렌더할 때는 버퍼 분리(detach)로 실패함. 운영 진단 기록을 보면 08-13 이전에는 렌더 경로를 탄 11건이 모두 성공했음. 그 이후 39건은 렌더 경로를 타지 않아 실패가 드러나지 않았음. #276에서 고침. 이번 골든셋은 10건 모두 렌더 경로를 타지 않아(텍스트 전용 9건, 임베드 이미지 경로 1건) #276이 G0 수치에 영향을 주지 않음.

**요금제 원가율.** 8장의 요금제 맥락은 v1.0 개산($0.01/문항)으로 계산돼 있었음. 실측 $0.0241을 넣으면 500문항 한도를 다 쓰는 학생 1인의 AI 원가는 약 $12.1, 환율 1,400원 가정 시 약 16,900원임. 요금 7,900원의 약 2.1배임. 한도를 다 쓰는 사용자가 드물더라도 원가율 안건은 RAG와 별개로 먼저 다뤄야 할 것으로 보임.

## 6. 한계

- 1인이 고른 10건 표본임. 과목이 소화기·순환기에 몰려 있음(소화기 4, 순환기 3, 간 1, 호흡기 1, 영상 1).
- 회차별 원가 변동이 커서, 3회 중앙값끼리도 ±20% 정도의 오차를 감안해야 함.
- PDF 페이지 판정은 자동 대조임. 사람 눈 확인은 같은 20개 표본으로 따로 함.
- 처리 시간은 클라우드 컨테이너에서 잰 값이라 Vercel 함수와 절대값이 다를 수 있음. G1은 같은 하네스로 잰 `on` 값과 비교하므로 비교 자체는 유효함.

## 7. 재현 방법

```
set -a; . <비밀 env>; set +a
export NODE_USE_ENV_PROXY=1 GEMINI_VERIFY_MODEL=gemini-2.5-flash-lite
cd <체크아웃>
npx tsx scripts/rag-eval/golden-run.ts --manifest <골든셋>/manifest.json \
  --user <계정 uuid> --confirm-email <이메일> --label g0-off --runs 3 --out <결과 폴더>
npx tsx scripts/rag-eval/compare-runs.ts --out <결과 폴더> --labels pre-c,g0-off
python3 scripts/rag-eval/page-index-check.py <결과 폴더> g0-off <골든셋>/manifest.json
npx tsx scripts/rag-eval/repeat-chunk-ids.ts <결과 폴더>/g0-off/NT2/run1.json   # 비용 발생
npx tsx scripts/rag-eval/golden-cleanup.ts --out <결과 폴더> --label g0-off,pre-c \
  --user <계정 uuid> --confirm-email <이메일>
```

manifest·결과 폴더에는 강의 원문과 생성 문항이 들어 있으므로 커밋하지 않음(v1.1 R3).
