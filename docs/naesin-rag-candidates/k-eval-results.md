## 2. K0 결과 — 이미지형 수확

진단(실행 기록만 다시 셈): IM1 이미지 문항의 블라인드 첫 판정 탈락률은 off 10/15, on 12/18로 비슷했음. 차이는 회복에 있었음 — off 는 보충이 잔여 용량 있는 그림을 묶음마다 4~5장 싣고 재작성 성공도 4/10이라 3회 모두 이미지형 3이었음. on 은 칸마다 단위 그림 1장이고, 보충이 방금 블라인드에 걸린 그림을 다시 실어 같은 실패를 되풀이함(재작성 성공 1/12).

- F1: 블라인드에서 폐기·강등된 문항의 그림을 실행 단위로 기록, on 보충의 이미지 칸은 정제 성공·블라인드 미탈락·재사용 잔여 용량이 있는 그림의 단위만 고름

- k0-im2 의 IM1 유형 합은 지식 16·임상 13·이미지 11(목표 12·16·12) — 이미지형을 채우는 대신 임상형이 모자람

- **사람 표본(60문항, on 30 + off 30)과 κ 는 라벨을 받아 채움.** κ < 0.6 이면 충실도 수치는 공표하지 않음

## 7. G1 판정과 조치

- 7장 규칙: 미달 항목은 항목당 1회 재조정, 그래도 미달이면 on 전환 보류(shadow 유지) + 원인 보고
- 근거 충실도는 조치표에 정해진 재조정이 없고, 고치려면 생성 지시(오답 배제·해설 근거까지 인용하게)를 바꾸고 E5 를 다시 돌려야 함(약 $7) — 예산 상한 안에서 할 수 없어 이번 PR 에서는 하지 않음
- 인용 정밀도는 사람 라벨이 0.95 를 넘으면 충족, 아니면 조치표대로 정규화 규칙·임계 재검토(오프라인, 비용 거의 없음)
- **그래서 on 전환은 보류하고 운영은 shadow 그대로 둠.** Phase 2(비평기) 판단 자료: 충실도 '부분·미지지' 31%(on), 검증기 경고율 0.53
