# 5.2 E·F 단위 검색·근거 팩 결과 (RAG 실행계획 v1.1 · PR H)

2026-10-05 · 전재현 · 도구: `scripts/rag-eval/pack-eval.ts` · 적용: `lib/rag/pack.ts`, `lib/rag/retrieve.ts`, `lib/rag/mode.ts`

## 결론

- **출제 단위마다 근거 팩을 만드는 검색 계층을 넣음.** 질의 4개로 dense 검색 → RRF → MMR → 근거 팩(1,200자 청크 6개, 4,500자 상한) 순서임. 근거가 모자란 단위는 예비 단위로 바꿔 끼움(D3). shadow·on에서만 돌고 진단에만 남기며, 생성은 아직 근거 팩을 쓰지 않음(PR I).
- **사전 기준 결과**
  - MMR(λ 0.7) 채택: R1 Recall@6 0.970 → 0.988, 팩 안 청크 간 평균 코사인 0.697 → 0.662
  - 글자 상한 4,500자 채택: Recall@6 변화 없음
  - τ 0.61 → 0.47: 계획 질의 기준으로 다시 정함(아래 설명)
- **τ를 바꾼 이유**
  - 0.61은 R1 질의(정답 청크를 보고 쓴 질의)로 정한 값임. 요약만 보고 쓴 계획 질의에서는 근거가 확인된 단위도 84%만 통과했음.
  - 사전에 정한 규칙은 '장기 계통이 다른 자료로 검색한 음성 대조군의 통과율이 5% 이하인 가장 작은 τ'였음. 이 규칙으로 0.47이 나왔고, 그때 근거 확인 단위는 177개 모두 통과했음.
- **τ 0.47의 한계를 분명히 적어 둠**
  - 같은 계통의 다른 강의(예: 위식도역류 단위를 위장관출혈 강의로 검색)는 41.5%가 통과함. 즉 τ는 '전혀 다른 내용'만 거르는 장치이고, 인접 주제까지 가려내지는 못함.
  - 근거 충실도는 PR I의 인용 검증과 E5(R2 근거 지지 라벨)에서 확인함. 미달이면 G1의 1회 재조정으로 τ를 다시 봄.
- **원가·지연.** 운영 DB shadow 실행에서 검색은 2.8~3.9초, 질의 임베딩 비용은 $0.0001 미만이었음. 생성과 나란히 돌아 처리 시간에 더해지지 않음(4장).

## 1. 구성

| 단계 | 내용 | 근거 |
|---|---|---|
| 질의 | 단위당 4개(개념·임상·비교·HyDE), voyage-4 query 임베딩 1회 묶음 호출(`rag.query`) | 5.2 D, PR G |
| 후보 | 질의마다 정확 코사인 top-20 → RRF(k=60) | E1~E3 |
| 순서 | MMR λ 0.7(관련도 = 질의 4개와의 최대 코사인, 다양성 = 이미 고른 청크와의 최대 코사인) | **H1** |
| 근거 팩 | 6개 · 4,500자(난이도 '상' 8개 · 6,000자). 순위대로 담고 넘치는 항목은 잘라 담음. 200자 미만으로 남으면 담지 않음 | **H2**, 5.2 F |
| 표기 | `[E1] (p.12) …`, OCR 청크는 `(p.12, 그림 속 글자(OCR))` | 5.2 F |
| 제외 | 캡션 청크(모델이 쓴 그림 설명)는 근거 팩에 넣지 않음. 이미지 단위의 그림 일치 판정에만 씀 | 자료 기반 원칙 |
| 충분성 | 단위 최고 유사도 ≥ τ(0.47) | **H3** |
| 이미지 단위 | 단위 질의와 그 그림 캡션 청크의 최고 유사도 ≥ τ일 때만 이미지 칸(R5) | **H5** |
| D3 | 칸의 단위가 근거 부족이면 유형이 맞는 충분한 예비로, 없으면 아무 충분한 예비로, 그것도 없으면 빈 칸. 이미지 칸은 이미지 예비가 없으면 텍스트 몫으로 넘김 | D3 |

청크 벡터는 업로드당 한 번 읽어 앱에서 계산함(`loadChunkVectors`).
- `match_material_chunks` RPC는 벡터를 돌려주지 않아 MMR을 할 수 없음.
- 단위 15개 × 질의 4개를 RPC로 하면 왕복이 60번임.
- 내용이 바뀐 낡은 벡터(`embedding_sha ≠ content_sha`)와 다른 모델의 벡터는 쓰지 않음.

## 2. 평가 방법

판정 기준은 실행 전에 적어 둠(원문은 `_golden_naesin/labels/pack-h-20261005.tgz`).

| # | 항목 | 기준 |
|---|---|---|
| H1 | MMR | R1 정답 질의 149단위의 Recall@6이 RRF 대비 0.01 넘게 떨어지지 않고, 팩 안 평균 코사인이 낮아질 때만 채택 |
| H2 | 글자 상한 4,500자 | 상한 없는 팩 대비 Recall@6이 0.01 넘게 떨어지면 6,000자로 올림 |
| H3 | 계획 질의 τ | 음성 대조군 통과율 ≤ 5%인 가장 작은 τ(0.40~0.80). 그때 근거 확인 단위 통과율 ≥ 0.90이면 채택, 아니면 0.61 유지 |
| H4 | '상' 팩 8개 | 판정 없음(5.2 F대로). E5-b에서 확인 |
| H5 | 이미지 단위 캡션 일치 | 판정 없음. H3의 τ로 IM1 통과율 보고 |

**자료**
- H1·H2·H4는 R1 정답 질의(149단위)로 잼.
- H3·H5는 PR G 평가의 계획 단위(골든셋 10건 × 2회, 302단위)로 잼.
- 근거 확인 단위(양성): 1위 청크가 같은 자료 R1 단위의 정답 인용구를 담은 계획 단위(177개)
- 음성 대조군: 계획 단위를 장기 계통이 다른 자료의 청크로 검색한 것(1,930쌍). 계통은 소화기·간 / 순환기 / 호흡기 / 영상·진단검사로 나눔.
- 참고로 같은 계통의 다른 자료(788쌍)도 재 둠. 내용이 실제로 겹칠 수 있어 판정에는 쓰지 않음.

## 3. 결과

### H1·H2·H4 (R1 정답 질의 149단위)

| 구성 | Recall@6 (전체 / 검토 59) | 팩 안 평균 코사인 | 팩 글자 평균 / 최대 | 잘린 단위 |
|---|---|---|---|---|
| RRF, 상한 없음 | 0.970 / 0.983 | 0.697 | 2,082 / 5,760 | 0 |
| **MMR, 상한 없음** | **0.988 / 0.977** | **0.662** | 2,076 / 5,730 | 0 |
| RRF, 4,500자 | 0.970 / 0.983 | 0.697 | 2,009 / 4,500 | 15 |
| **MMR, 4,500자 (채택)** | **0.988 / 0.977** | 0.663 | 2,006 / 4,500 | 10 |
| '상' 8개 · 6,000자 | 0.987 / 0.983 | 0.689 | 2,618 / 6,000 | 16 |

- **H1 충족.** MMR이 전체 Recall을 0.018 올리고 팩 중복을 줄였음. 검토 59단위는 −0.006으로 기준(−0.01) 안임.
- **H2 충족.** 4,500자 상한에서 잘린 단위가 10~15개 있었지만 Recall은 그대로였음. 순위가 낮은 근거만 잘려 나감.

### H3 τ (계획 단위)

| τ | 음성(다른 계통) 통과 | 같은 계통 다른 강의 통과(참고) | 근거 확인 단위 통과 | 계획 단위 전체 통과 | D3 모의: 교체 / 빈 칸 |
|---|---|---|---|---|---|
| 0.45 | 7.3% | 47.8% | 1.000 | 1.000 | 0 / 0 |
| **0.47 (채택)** | **4.9%** | 41.5% | **1.000** | 1.000 | 0 / 0 |
| 0.50 | 1.5% | 35.4% | 1.000 | 1.000 | 0 / 0 |
| 0.55 | 0.5% | 21.1% | 0.989 | 0.990 | 1 / 0 |
| 0.58 | 0.1% | 14.5% | 0.966 | 0.954 | 10 / 0 |
| 0.61 (종전) | 0% | 8.6% | 0.842 | 0.861 | 25 / 1 |
| 0.64 | 0% | 4.6% | 0.712 | 0.742 | 34 / 18 |

D3 모의는 실행 20회 합계임. 칸은 2문항 × 5묶음 쿼터, 예비는 5개임.

**H3 판정.** τ_plan은 0.47이고 그때 근거 확인 단위 통과율은 1.000(≥ 0.90)이라 채택함.
- 0.61에서는 근거가 확인된 단위의 16%가 '근거 부족'으로 잘리고, 25칸이 예비로 바뀌며, 1회는 빈 칸이 생김.
- 0.47에서는 골든셋에서 D3가 한 번도 작동하지 않음. 계획이 짚은 쪽을 근거 팩에 찾아오는 비율이 99.7%(PR G)라는 결과와도 맞음.

**한계.** 음성 대조군이 쉬운 쪽(다른 장기 계통)이라, τ 0.47은 '같은 과목의 다른 주제'를 가려내지 못함(41.5% 통과). 그래서 τ는 근거 충실도의 보증이 아님.
- 생성 단계(PR I)의 인용 검증: 인용구가 근거 팩 원문에 실제로 있는가
- E5의 R2 근거 지지 판정

이 둘이 실제 방어선임. E5에서 '부분·미지지' 문항이 낮은 유사도 단위에 몰리면 G1 미달 조치(1회 재조정)로 τ를 올림.

### H5 이미지 단위 (IM1, 2회)

- 계획의 이미지 단위는 11개였음. 그 그림 캡션과의 최고 유사도는 0.35~0.73이었음.
- τ 0.47에서는 10/11이 그림 일치이고, 0.61이었다면 5/11이었음.
- 불일치 1개(0.35)는 D3 처리에서 다른 이미지 단위로 바뀌거나 텍스트 몫으로 넘어감.
