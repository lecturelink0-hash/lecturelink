# CPX 환자 3D 모델 교체 후보 선정 (2026-08-25)

## 배경

현행 환자 GLB 8종은 Quaternius Ultimate Animated Character Pack(CC0)의 Casual/OldClassy 캐릭터로,
계측 결과 **2.7~2.9등신**(머리가 신장의 35~37%, 가랑이 높이 30%, 몸통 33%)이었다. 진찰 부위 비율표
(`EXAM_REGION_FRAC`: 목 .84·가슴 .70·복부 .55)는 실제 인체 기준이라, 눕힌 모델에서 '가슴' 카메라가
얼굴에 떨어지는 등 복부·흉부 시진/촉진/타진/청진 프레이밍이 부자연스러웠다.

## 경과

1. 1차 시도(폐기): poly.pizza 계측 비율을 기존 Quaternius 리그에 본 단위로 이식(정점 워프). 비율은 맞았으나
   원본의 큰 머리·저폴리 몸을 늘린 결과물이 기괴하다는 피드백으로 폐기. 도구·결과물 모두 제거.
2. 2차(현재): poly.pizza 모델을 **원형 그대로** 후보로 도입. 렌더러는 후보를 그대로 띄우도록 최소 대응만 했다.

## 후보 수집·계측

- poly.pizza 검색 페이지(서버 렌더, API 키 불필요)에서 human/person/man/woman/character base/elderly/casual/
  rigged character 등 40여 검색어로 ID 수집 → People & Characters 112종 GLB 다운로드(CDN은 UA·Referer 필요).
- `scripts/avatar/measure_glb.py` (순수 Python, 삼각형-평면 슬라이스 단면)로 등신비·가랑이 높이·목 높이·
  흉부/엉덩이 폭·리그/애니메이션 유무를 계측 → [polypizza-human-catalog.csv](polypizza-human-catalog.csv)
  (실제 비율 근접순 정렬, `note` 열이 비어 있으면 유효 계측).
- 선정 기준: 실제 성인 비율(6~8등신, 가랑이 ≈ .47~.50) · 환자에 어울리는 중립 복장 · 상업 이용 가능(CC0 우선) ·
  렌더러 호환(리그·Idle 클립·`Head` 본이 있으면 눕기 포즈·호흡 애니메이션이 자연스러움).

  접촉만), 팔뚝–반대편 상완 6.6cm. 어깨폭이 좁은 모델(여 0.108 vs 남 0.147)은 가로 성분을 어깨 반폭 비율로 줄이고
  팔뚝을 더 세워 상완 관통을 피함(`lateralK`).
- 측와위: 아래쪽 팔은 어깨 높이를 유지한 채 침대 위로 앞으로 뻗고, 위쪽 팔은 팔꿈치를 침대에 대고 팔뚝을 앞으로 눕혀
  손바닥이 침대 표면에 놓임(위쪽 어깨가 침대 위 20cm 뿐이라 팔을 곧게 내리면 침대를 뚫음). 침대 접촉 기준 바운딩박스는
  팔·손을 제외(안 그러면 손이 최저점이 되어 몸통이 뜸).
- 결과: 남/여 각 팔짱·좌측와위·우측와위 재캡처 — 보고서 10차 섹션 이미지 교체.

## 12차: 팔짱 손을 어깨 바로 위로(IK) · 측와위 손바닥 아래로 (2026-08-26)

피드백: "X자 팔의 손이 어깨 바로 위에 있어야 하는데 변신 포즈 같다. 좌측와위의 오른손·우측와위의 왼손 손바닥이
바닥을 향해야 한다 — 지금은 한쪽 어깨가 꺾여 보인다."

- 팔짱: 방향 지정 대신 **2본 IK**(`ik2`) — 손목 목표를 반대편 어깨 관절 + (0, +5cm, +3cm/+17cm) 로 주고 팔꿈치는 pole
  (가슴 앞·아래) 쪽으로 해석적으로 배치. 오른손은 왼쪽 어깨 위(가슴 쪽), 왼손은 오른쪽 어깨 위(그 앞)로 깊이를 분리해
  팔뚝 간격 9.5cm. 손바닥은 어깨 위에 평평하게(아래 항목의 롤).
- 손바닥 방향: 손목 본 로컬축 중 손 메시가 가장 얇은 축(−Z, 두께 0.7mm vs 1.9/2.5mm)을 손바닥 법선으로 판정하고
  바인드 T포즈에서 아래를 향하도록 부호를 정한다(`detectPalmAxis`). `rollToward` 로 팔뚝(회내)·손목을 본 축 둘레로
  굴려 법선이 월드 −y(침대/어깨)를 향하게 한다. 측와위 위쪽·아래쪽 손 모두 손바닥이 침대를 향하고, 어깨 비틀림이 사라짐.
- 함정: 로드 시 기본 포즈가 팔을 내린 자세라 "아래를 향한 축" 휴리스틱은 손 길이 축을 잡는다 → 기하(두께) 기반으로 판정.

## 13차: 팔짱 손 위치 중앙 쪽으로·교차부 살 관통 제거 (2026-08-26)

피드백: "손 위치를 조금만 더 중앙 쪽으로, 팔이 겹치는 부위에 살 부분 픽셀 날림이 없게."

- IK 손목 목표를 안쪽으로 4cm(남 x ±0.147 → ±0.107, 여 ±0.108 → ±0.068), 왼손 목표를 앞 20cm·위 8cm 로, 팔꿈치
  pole 은 오른팔 가슴 쪽(z 0.08)·왼팔 앞(z 0.6)으로 → 팔뚝 중심 간격 남 13.3cm·여 14.9cm(반지름 합 ≈9cm 초과, z-fighting 없음).
  손–반대편 상완 거리 5.3~5.7cm 는 손이 어깨 위에 얹힌 접촉.

## 14차: 반팔 소매를 진짜 천 쉘로 · 팔꿈치 뭉개짐 원인 (2026-08-26)

피드백: "X자 교차에서 팔꿈치가 너무 블러 처리되고, 반팔 소매와 살이 구분되지 않는다."

- 원인: 후보 2의 소매는 피부 삼각형에 셔츠 색만 입힌 것이라(상완 축 62%까지) 팔을 굽히면 소매 경계가 팔꿈치 접힘
  위에 걸려 뭉개져 보였다. 팔꿈치 자체는 손을 어깨 위에 얹는 자세에서 굴곡이 ~75°(상완·팔뚝 각 22cm, 어깨 간 거리
  ~27cm)라 저폴리 리그 스키닝이 접히는 한계 — 손을 앞으로 보내 굴곡을 줄이면 팔뚝이 같은 깊이에 놓여 오히려 겹친다
  (간격 13.3 → 2.4cm) → 자세는 13차 값을 유지.
- 대응: `restyle_outfit.py` split 규칙에 **쉘 옵션** — 소매·몸통 노출 피부 삼각형을 복제해 법선 방향 4mm 띄운 별도
  프리미티브(`Shirt`)로 만들고 원래 피부 삼각형은 피부로 남긴다(진짜 소매단이 단차로 보임). 소매 경계는 상완 50%
  (팔꿈치 접힘에서 떨어진 위치)로 이동. 서기 정면에서 소매단이 뚜렷한 단차로 구분됨.
- 재현: `tmp/build_final.sh` 체인 — 원본 → `cand2_casual`(바지 통·소매 쉘·Hoodie 헤어) → `touch arm` → `touch matte` → 신장 6종.

## 15차: 팔꿈치 정점 분할 · 소매 쉘 균열 수정 · 팔짱을 가슴 앞으로 (2026-08-26)

피드백: "팔꿈치 부근 정점을 분할해서 뭉개짐을 줄여 봐" → 이어서 "오른쪽 팔이 가슴 픽셀에 묻혀 있다. 양팔을 가슴 위로 올려라."

- **팔꿈치 정점 분할** `restyle_outfit.py` `elbow_subdiv`(touch 옵션 `"elbow_subdiv": 2`): 상완 축 t∈[0.72, 1.38](팔꿈치=1.0,
  하완은 1+t')의 띠 안 삼각형을 1:4 로 2회 분할(남 342·여 336 변, 삼각형 2456→3140 / 2166→2838). 이 리그는 정점이
  삼각형마다 복제된 플랫 셰이딩 메시라 변을 인덱스가 아니라 **좌표**로 식별해 띠 경계 삼각형을 1:2·1:3 으로 함께 쪼갠다
  (균열 없음). 새 정점은 위치·UV 선형 보간, 법선 재정규화, 관절 가중치 병합 후 상위 4개 정규화. 가중치 smoothstep
  재배정(`elbow_smooth`)도 구현했으나 렌더에서 차이가 없어 기본 0. 팔꿈치 자체의 시각적 개선은 완만(면이 잘게 나뉘어
  접힘 경계가 조금 또렷) — 뭉개짐의 큰 부분은 자세(아래) 쪽 원인이었다.
- **소매 쉘 균열(회귀 수정)**: 14차 쉘은 정점별 법선으로 띄웠는데 플랫 법선 메시라 모서리마다 쉘 삼각형이 벌어져 피부가
  실선으로 비쳤다(14차 검증 렌더는 브라우저가 이전 GLB 를 캐시한 것이었음). 같은 좌표의 법선을 합친 **welded normal**
  로 띄우고, 몸통 표면인 원본 탱크톱 프리미티브(`Beach_Body#1`)도 같은 두께로 함께 띄워(split 규칙 8번째 인자) 쉘과
  한 면을 이루게 했다 → 정면·상단·측면 근접에서 실선 없음. QA 하네스는 GLB 로드에 캐시 버스터를 붙임.
- **팔짱을 가슴 앞으로**: 몸통 앞면이 어깨 관절보다 ~11cm 앞(남 175: z 0.175 vs 0.061)인데 13차 안쪽 손목 목표는 관절
  기준 +2cm 라 안쪽 팔뚝이 가슴 속에 있었다. 이 리그의 팔은 상완 0.17+전완 0.22m 로 짧아 "손을 반대편 어깨 관절에 +
  가슴 앞 + 팔뚝 두 겹"을 동시에 만족할 수 없다(IK 가 완전 신전에 걸려 폴로 팔꿈치를 앞으로 못 뺌). 그래서 손을 어깨
  반폭의 60%(남 8.8·여 6.5cm)만큼 안쪽(쇄골·삼각근 앞)에 두고 안쪽 팔뚝 z=+0.16, 바깥 팔뚝 z=+0.31, 팔꿈치 폴은
  바깥·아래·앞. 지표 `__chest()`: 안쪽 팔뚝 중심선−몸통면 남 4.5·여 5.2cm(팔뚝 반경 이상), 바깥−안쪽 9.8·11.3cm,
  팔뚝 중심선 최소 거리 5.8·9.0cm(손이 반대 팔뚝 밑에 닿는 지점). 측면 뷰에서 양팔이 가슴 앞, 정면에서 관통 없음.

## 16차: 구강진찰용 입 — 실제 구강 기하 + 모프 `MouthOpen` (2026-08-26)

피드백: "CPX 구강진찰 구현하려면 입도 만들어야 해. 입 만들어줘."

- 현황: 앱은 기존 모델의 `Face` 재질 위에 데칼(눈꺼풀 쿼드 + y축 스케일하는 어두운 원판)만 얹었고, 후보 모델은 `Face`
  재질이 없어 눈 깜빡임·입이 전혀 없었다. 어떤 GLB에도 입 메시·턱 본·모프 타깃이 없었다(README 의 "자체 눈·입 지오메트리"
  표기는 눈·눈썹만 맞는 말이었음). 구강 진찰 버튼 19종 중 15종은 `avatarTarget='chest'` 로 매핑돼 카메라가 가슴을 비춘다.
- 구현 `scripts/avatar/mouth_build.py`(`restyle_outfit.py` touch 옵션 `"mouth": true`):
  - 랜드마크 자동 계측(정중선 프로파일): 코끝·코밑(코끝 아래 첫 1.2cm 함몰)·턱(앞쪽이 코끝의 78% 이상인 최하 정점) →
    입 중심 = 턱→코밑의 42%(남 175: z 1.70cm, 여 165: 1.49cm), 입 반폭 = 얼굴 반폭의 50%(2.18 / 2.14cm).
  - 얼굴 피부에 **진짜 구멍**: 입술 바깥 타원과 교차하는 피부 삼각형 제거 후 경계 루프(좌표 키)↔입술 바깥 링을 각도순
    브리지 삼각화. 별도 메시 `<Head>_Mouth`(같은 스킨, Head 본 100%)에 입술 링(2단, 살짝 볼록)·구강 내벽(깊이 1.5cm)·
    뒷벽(인두)·위/아래 치열(각 8개)·혀(바닥 돔)·목젖. 재질 Lips/MouthCavity/Pharynx/Teeth/Tongue/Uvula(단색, 양면).
  - **모프 타깃 `MouthOpen`** 하나로 닫힘(기본: 입술선 + 0.7mm 슬릿, 내부 조각은 슬릿 선에 접힘)↔벌림(안쪽 링 위 0.4·아래
    1.45cm, 턱 하강 1.2cm·뒤로 0.35cm — 입선 아래 앞면 피부의 smoothstep 델타). glTF 규격상 같은 메시의 다른 프리미티브

## 채택 시 남는 작업

- 채택 후보를 `patient_{male|female}[_old|_child|_infant].glb` 규약으로 복사(성별·연령 변형은 같은 계열에서 확보).
- 얼굴 데칼(깜빡임)은 `Face` 재질 + `Head` 본 전제 — 후보는 자체 눈·눈썹 지오메트리라 데칼 없음(입은 16차 모프로 해결).
  깜빡임이 필요하면 Quaternius 계열의 `Eye`/`Eyebrows` 재질을 앵커로 쓰도록 `computeFaceAnchors` 확장.
- `GLB_COLOR_FIX` 가 `Skin` 재질을 #e8b89a 로 덮어씀(cand1·2) — 원래 피부톤 유지하려면 예외 처리.
- 리그 없는 후보(3)는 눕혀도 A포즈 그대로(팔이 벌어짐) — 채택 시 리깅 또는 리그 있는 계열 선택 권장.
- 소아·유아 비율표(`CHILD_/INFANT_EXAM_REGION_FRAC`)는 현행 모델 기준 — 후보 채택 시 재산정.
