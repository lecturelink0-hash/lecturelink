# LectureLink 교수용 UI 개선 보고

- 작성일: 2026-07-30
- 대상: LectureLink Faculty 교수용 화면
- 기본 방향
  - 주요 이용자인 50대 이상 교수자가 작은 글씨 없이 읽을 수 있도록 본문·버튼·보조 문구의 최소 글자 크기를 상향함.
  - 제목의 최대 크기는 과도하게 키우지 않고, 작은 글씨의 하한을 높이는 방식으로 조정함.
  - 비유적 표현과 중복 설명을 줄이고 행동 중심의 짧은 문구로 변경함.
  - 녹색·크림색 중심의 기존 브랜드 색상 안에서 화면별 색상과 상태 표현을 통일함.

## 1. 공통 상단 영역

- 교수용 브랜드 표기를 `Lecturelink FACULTY`로 통일함.
- 상단 메뉴의 `대시보드`를 `홈`으로 변경함.
- 상단 메뉴의 `내 강의실`을 `통합 관리`로 변경함.
- 상단 메뉴 순서를 `홈 → 통합 관리 → 자료 개선 → 예습자료 → 형성평가 → 문항 검토`로 변경함.
- 상단 메뉴와 계정 영역의 글자 크기를 교수용 가독성 기준에 맞게 상향함.
- 모바일 메뉴에도 동일한 명칭과 순서를 적용함.
- `사용 설명서` 물음표가 원의 중앙에 오도록 크기·줄 높이·정렬을 보정함.

## 2. 홈

- 홈 상단의 교수용 표기를 `LECTURELINK FACULTY`로 변경함.
- 원하는 작업 카드 순서를 `강의자료 개선 → 예습자료 → 형성평가 → 문항 검토`로 변경함.
- 작업 카드 설명을 짧고 직접적인 문장으로 정리함.
- 최근 작업과 통합 관리 영역의 글자 크기와 카드 위계를 교수용 기준으로 조정함.
- 차시 카드에서 기능명 나열을 제거하고 차시명·학기 등 차시 정보가 먼저 보이도록 변경함.

## 3. 통합 관리

- `내 차시 작업공간` 앞의 단계 번호를 제거함.
- 불필요한 `차시 목록` 문구를 제거함.
- 새 차시 만들기와 이용 순서를 한 화면에서 이해할 수 있도록 배치함.
- 이용 순서는 새 차시 생성 후 자료 개선·예습자료·형성평가·학습 결과로 이어지는 흐름이 보이도록 구성함.
- 네 가지 교수 기능을 순차형이 아닌 병렬형 카드로 표현함.
- 새 차시 만들기 카드의 불필요한 투명 테두리 장식을 제거함.
- 새 차시 생성 버튼의 글꼴과 굵기를 다른 버튼과 통일함.
- 차시 생성 직후 추가 완료 메시지와 시각 효과가 표시되도록 함.
- 생성된 차시가 작업공간 목록에서 바로 확인되도록 이동 흐름을 보완함.
- 차시 카드에서 `강의자료·예습자료·형성평가·학습 결과` 반복 문구를 제거함.
- `순환기학`, `부정맥 약물` 등 차시 제목을 더 크게 표시함.

## 4. 차시 상세 화면

- 학생 참여 코드 영역을 제거함.
- `순환기학 수업 준비를 이어가세요`를 한 줄의 넓은 제목으로 정리함.
- 강의자료 영역에 단계 번호 `1`을 유지함.
- 생성 결과 영역에 단계 번호 `2`를 추가함.
- 업로드 자료 보호 안내를 별도의 큰 하단 경고 카드에서 강의자료 상단 우측 안내 영역으로 이동함.
- 보호 안내의 붉은 경고색을 제거하고 교수용 UI의 녹색 계열로 통일함.
- 보호 안내 문구를 다음 핵심 내용 중심으로 단축함.
  - 사용자가 삭제한 자료는 서버에서도 삭제됨.
  - 업로드 자료는 모델 학습에 사용되지 않음.
  - 외부에 배포되지 않음.
  - 선택한 기능의 분석에만 사용됨.
- 새 자료 업로드 버튼을 강의자료 설명 아래에 배치함.
- 업로드 자료 삭제 기능과 삭제 확인 절차를 추가함.
- 업로드된 자료 카드에서 PDF 형식·쪽수·용량 정보를 제거함.
- 업로드 자료의 파일명을 크게 표시하고 긴 제목도 잘리지 않도록 줄바꿈을 허용함.
- 자료별 작업 버튼을 `형성평가 만들기 →`, `예습자료 만들기 →`, `자료 개선하기 →`로 변경함.
- 각 작업 버튼에 우측 화살표를 추가해 다른 제작 화면으로 이동한다는 점을 명확히 함.
- 자료별 작업 버튼을 파일명 아래에 배치해 제목 공간을 확보함.
- 하단의 별도 학생 결과 카드와 우측 차시 현황 카드 중복을 제거함.
- 생성 결과의 `1개의 결과물` 등 개수 문구를 제거함.
- 생성 결과를 세로 목록에서 `형성평가·예습자료·자료 개선` 가로 3열 카드로 변경함.
- 세 결과 카드에 기능별 배경색·아이콘·장식 요소를 적용함.
- 생성 결과 카드의 불필요한 고정 높이와 하단 여백을 제거함.
- 생성 결과 카드에서 제출 인원·평균 정답률 문구를 제거함.
- 생성 결과 카드에서 `검토 필요`, `승인 완료` 등의 상태 배지를 제거함.
- 생성 결과 카드에는 결과물 제목과 우측 이동 화살표만 남김.

## 5. 차시·강의자료 선택 공통 흐름

- 자료 개선·예습자료·형성평가에서 동일한 공통 선택 UI를 사용하도록 정리함.
- 차시 영역의 중복된 `차시`, `차시 선택`, 설명 문구를 제거함.
- `차시 선택` 제목과 바로 아래 `차시를 선택하세요` 선택 상자만 남김.
- `새 차시 만들기` 버튼을 누르면 기존 차시와 강의자료 선택이 초기화되도록 변경함.
- 기존 차시가 선택된 채 새 차시 입력창이 열리는 상태 충돌을 해소함.
- 새 차시 입력 영역에 `차시명`, `학기` 라벨을 명확히 표시함.
- `새 차시 만들기`와 `만들고 선택` 버튼의 글자 굵기를 통일함.
- 로컬 미리보기에서 실제 서버 API를 호출해 생성에 실패하던 문제를 수정함.
- 로컬 미리보기에서는 새 차시를 즉시 목록에 추가하고 자동 선택하도록 함.
- 새 차시에는 등록 자료가 없으므로 생성 직후 `새로 업로드` 화면을 자동 표시함.
- 차시 선택 전후에 업로드 카드 폭이 달라지던 문제를 수정함.
- 선택 전·후 업로드 카드 폭을 동일한 770px로 맞춤.
- 강의자료 선택 영역을 `등록된 강의자료 / 새로 업로드` 두 탭으로 구분함.
- 선택 상자·입력창·버튼·탭의 높이와 글자 크기, 색상을 통일함.

## 6. 자료 개선

- 제목과 설명의 글자 위계를 교수용 가독성 기준으로 조정함.
- 공통 차시·강의자료 선택 흐름을 적용함.
- 차시와 자료를 선택한 뒤 개선 기준을 설정하는 흐름이 순서대로 보이도록 함.
- 선택한 강의자료가 작업에 사용된다는 확인 표시를 강화함.

## 7. 예습자료

- 상단 제목을 `예습자료와 함께 수업을 시작하세요`로 단순화함.
- 공통 차시·강의자료 선택 흐름을 적용함.
- 학습자 선택에서 `의예과 / 1학년`, `의학과 / 2학년`처럼 과정명과 학년 사이에서 줄바꿈되도록 변경함.
- `의예과 1학/년`처럼 학년 단어가 어색하게 분리되는 문제를 해결함.
- `예습 확인 문항 2개 포함` 아래의 부가 설명을 제거함.
- `예습 확인 문항 2개 포함` 글자를 확대함.
- 확인 문항 체크 카드의 체크박스 크기·세로 정렬·높이·안쪽 여백을 보정함.

## 8. 형성평가

- 상단 제목을 `형성평가로 이해도를 확인하세요`로 단순화함.
- `강의의 끝에서` 등 불필요한 앞 문구를 제거함.
- 공통 차시·강의자료 선택 흐름을 적용함.
- 자료에서 형성평가 제작 화면으로 이동할 때 해당 자료가 미리 선택되도록 연결함.
- 형성평가 상세 화면에서 해당 평가 세트의 제출 인원과 평균 정답률을 확인할 수 있도록 데이터 구조를 보완함.
- 차시 상세 화면에서는 해당 통계를 노출하지 않고 결과물 제목만 표시함.

## 9. 자료와 결과 관리

- 강의자료 삭제 API와 화면 동작을 연결함.
- 삭제 시 스토리지 파일과 자료 정보가 함께 삭제되도록 처리함.
- 형성평가별 통계를 계산할 수 있도록 분석 응답에 결과물별 통계 구조를 추가함.
- 형성평가 편집 화면의 구성과 글자 위계를 정돈함.

## 10. 검증

- 주요 수정 단계마다 로컬 교수용 화면을 브라우저에서 직접 확인함.
- 홈·통합 관리·차시 상세·자료 개선·예습자료·형성평가 화면을 비교 확인함.
- 새 차시 생성, 기존 선택 초기화, 자동 선택, 새 자료 업로드 전환을 실제로 실행해 확인함.
- 차시 선택 전후 업로드 카드 폭을 측정해 770px로 동일함을 확인함.
- 생성 결과 카드의 통계·상태 문구가 제거된 것을 확인함.
- TypeScript 타입 검사를 통과함.
